우리집 가계부 v1.3 · Google Drive 동기화

[무엇이 필요한가요?]
- Google 계정 1개
- 무료 정적 웹 호스팅 (예: GitHub Pages)
- Google Cloud 프로젝트에 웹용 OAuth 클라이언트 ID 1개 (클라이언트 비밀키는 사용하지 않음)
- DB, Cloudflare Worker, KV, 서버 프로그램은 필요 없습니다.

[최초 1회 설정]
1. https://console.cloud.google.com/ 에서 프로젝트를 선택하거나 새로 만듭니다.
2. https://console.cloud.google.com/apis/library/drive.googleapis.com 에서 Google Drive API를 사용 설정합니다.
3. https://console.cloud.google.com/auth/overview 에서 Google 인증 플랫폼(브랜딩/대상)을 설정합니다.
   개인 사용용으로 테스트 상태라면 '테스트 사용자'에 자신의 Gmail을 추가합니다.
4. https://console.cloud.google.com/auth/clients 에서 '웹 애플리케이션' OAuth 클라이언트를 만듭니다.
   승인된 JavaScript 원본에 배포할 주소를 등록합니다.
   예) GitHub Pages 주소가 https://myname.github.io/budget/ 라면 등록할 원본은 https://myname.github.io 입니다.
   Google OAuth에서 file:// 직접 실행은 지원되지 않습니다.
5. index.html을 정적 웹 호스팅에 올리고 PC/모바일에서 같은 주소로 열어 주세요.
6. 가계부 > 데이터·백업·동기화 화면에서 발급한 클라이언트 ID를 붙여넣고 'Google 로그인'을 클릭합니다.
7. PC/모바일에서 같은 Google 계정과 클라이언트 ID를 사용합니다. Drive에 만들어지는 우리집가계부_sync.json 파일 1개를 공유합니다.

[매일 사용]
- 지출 입력/수정은 로컬에 즉시 자동 저장됩니다. 로그인된 동안에는 Drive에도 동기화됩니다.
- 다음에 가계부를 새로 열 때 다시 Google 로그인을 눌러야 할 수 있습니다.
- 기기를 바꾸기 전에 Drive에 저장 완료 표시를 확인하세요.
- 충돌 시 자동 덮어쓰지 않고 사용자 선택을 받습니다. 동시 저장 순간의 경합은 완전히 막지 못합니다.
- 정기적으로 JSON 백업을 다운로드하세요. 엑셀(.xlsx) 다운로드도 계속 지원합니다.

[보안·주의]
- Google Drive drive.file 권한을 요청하며, 앱에서 만든 파일에 접근합니다.
- Google 클라이언트 ID는 공개되어도 되는 식별자이지만 클라이언트 비밀키는 절대 HTML에 넣으면 안 됩니다.
- 가계부 데이터는 Google Drive에 일반 JSON으로 저장됩니다. 종단 간 암호화가 아닙니다.
- 테스트 사용자 제한과 테스트 앱 권한 만료 등은 Google 정책에 따라 달라질 수 있습니다.
- 로컬 브라우저 데이터 삭제 시 아직 업로드하지 않은 기록은 복구할 수 없습니다.
