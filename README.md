# 우리집 가계부 v1.5 — 암호화 잠금 / Google Drive 동기화

## 동작 방식

- 공개 GitHub 저장소에는 `index.html`, `.gitignore`, `README.md`만 업로드하세요.
- 시작 화면은 완전 불투명 잠금 화면이며, 가계부는 암호 해독에 성공하기 전까지 표시되지 않습니다.
- 사용자 ID는 `joo`입니다. 비밀번호는 **코드에 포함되지 않습니다**. 최초 로그인 시 사용자가 입력한 비밀번호로 암호화 키를 만들고, 해당 키로 데이터 전체를 암호화합니다.
- 보안상 비밀번호/비밀번호 해시를 Google Sheets에 저장하지 않습니다. 대신 PBKDF2-SHA256(310,000회) + AES-256-GCM으로 암호화된 JSON만 Drive와 브라우저에 저장합니다.
- Google OAuth는 기존 Drive API `drive.file` 권한을 그대로 사용합니다. 다른 사람은 본인 Google Drive에 로그인할 수 없고, Drive에 저장된 암호문은 비밀번호 없이 해독할 수 없습니다.

## 설치

1. ZIP에서 `index.html`, `.gitignore`, `README.md`를 GitHub 공개 저장소 `joy2734/homeExpendManager`의 `master` 브랜치 최상단에 업로드합니다. 실제 개인 `.json`은 업로드하지 마세요.
2. GitHub Pages에서 `master` / `/ (root)`로 배포합니다.
3. `https://joy2734.github.io/homeExpendManager/`에 접속합니다.
4. 잠금창에서 아이디 **joo**, 개인 비밀번호, Google OAuth 클라이언트 ID를 입력합니다. **첫 설정 시** 비밀번호 확인 칸에도 동일하게 입력합니다.
5. `Google 로그인하고 가계부 열기` → Google 계정 선택 → 필요한 Drive 권한 허용.
6. 이전 Drive 파일 `우리집가계부_sync.json`이 있다면 마이그레이션 안내에 따라 신규 암호화 파일 `우리집가계부_secure_v2.json`이 생성됩니다. 데이터가 정상인지 확인 후 이전 평문 파일을 **Drive에서 삭제하고 휴지통을 비우세요**. Drive에 보관된 이전 파일 버전과 로컬 평문 백업도 확인하여 정리하세요.
7. 두 번째 기기에서는 같은 웹 주소, Google 계정, 사용자 ID와 비밀번호로 로그인합니다. 비밀번호 확인 칸은 새 암호화 파일을 만들 때만 필요합니다.

## 중요: 기존 데이터를 잃지 않으려면

- 이전에 사용하던 페이지에서 **일반 JSON 백업을 먼저 안전한 개인 폴더에 다운로드**하세요. 공용 GitHub에는 절대 올리지 마세요.
- 기존 로컬/Drive 데이터가 있는 경우 처음 로그인 과정에서 평문을 새 암호화 파일로 옮기도록 안내합니다.
- JSON이 암호화되었다고 해서 기존에 공개 저장소에 커밋된 데이터가 사라지는 것은 아닙니다. 과거 Git 커밋 내역도 점검해야 합니다.
- 저장된 비밀번호는 어디에도 남기지 않습니다. 비밀번호를 잊으면 암호화된 데이터를 복구할 수 없습니다.
- 비밀번호를 새로 변경하고 싶다면 향후 별도의 데이터 재암호화 기능이 필요합니다. 현재는 비밀번호 변경 기능이 없습니다.
- 기존에 채팅 등으로 공유한 비밀번호는 재사용하지 말고 **새로운 강력한 비밀번호**로 최초 설정하세요.
- Google OAuth 연결이 풀리면 재로그인해야 합니다. Google 로그인은 Google 서버를 통해 검증되며, 암호화 비밀번호는 서버로 전송하지 않습니다.
- 이 방식은 공개 정적 페이지 보호를 위한 **클라이언트 측 암호화**이지 별도 서버의 로그인 시스템이나 접근 제어가 아닙니다. GitHub HTML 코드는 누구나 열 수 있지만 가계부 원본 데이터는 암호화됩니다.
- 일반 JSON 및 Excel 다운로드 파일은 암호화되지 않은 평문이므로 신중하게 보관하세요. 암호화 JSON 백업을 우선 권장합니다.
- 실제 본인 Google OAuth 계정 연결 및 동기화는 이 환경에서 실사용 검증할 수 없어, 최초 배포 후 본인 환경에서 반드시 확인해야 합니다.
