YOUR DATA, YOUR CONTROL

데이터 · 백업 · 동기화

GitHub에는 빈 가계부 코드만 공개합니다. 개인 자료는 로컬·비공개 Drive에만 보관합니다.

① 암호화 자동 저장

입력한 데이터는 AES-GCM으로 암호화한 후 현재 브라우저의 localStorage에 자동 저장됩니다. 인터넷 없이도 사용할 수 있지만, 방문 기록/사이트 데이터 삭제나 다른 브라우저 사용 시에는 데이터가 옮겨지지 않습니다.

② JSON 파일 백업 · 불러오기

일반 JSON 백업은 암호화되지 않은 평문 파일입니다. 안전한 장소에만 보관하세요. 데이터 전체(고정비·지출 기록·카드 사용처)를 JSON 파일로 내보냅니다. 파일을 다시 선택하면 해당 백업 내용으로 복원됩니다.

③ 엑셀(.xlsx) 다운로드

현재 저장된 전체 데이터를 엑셀 파일로 내보냅니다. 요약 · 고정비 내역 · 지출 기록 · 카드 사용처가 각각 시트로 저장되며, 금액은 엑셀에서 계산할 수 있는 숫자 형식으로 기록됩니다. 외부 라이브러리와 인터넷 연결이 필요하지 않습니다.

엑셀은 확인·분석용 내보내기입니다. 수정한 내용을 다시 가져와 가계부에 반영하려면 JSON 백업·복원을 이용하세요.

④ JSON 파일에 직접 저장 (지원 브라우저)

Chrome·Edge 등 지원 브라우저에서는 JSON 파일을 한 번 선택한 뒤, 변경 내용을 같은 파일에 저장할 수 있어요. 브라우저 보안 정책에 따라 HTTPS 또는 localhost에서만 동작할 수 있습니다. 파일로만 열었을 경우에는 위의 다운로드/불러오기 방식이 가장 안정적입니다.

연결된 작업 파일 없음

브라우저에 자동 저장된 내용과 파일 저장 내용은 별개입니다. 파일을 열 때는 현재 내용을 덮어쓸지 확인합니다.

⑤ PC ↔ 모바일 · Google Drive 동기화

Google 계정의 AES-GCM 암호화된 비공개 JSON 파일 1개를 저장하고, PC와 모바일에서 같은 파일을 사용합니다. 첫 연결 시 기존 Drive 파일이 있으면 자동으로 찾아 불러옵니다. 별도 DB나 Worker는 없습니다. 처음에는 Google Cloud에서 웹용 OAuth 클라이언트 ID를 한 번 발급해야 합니다. 등록 후에는 로그인 화면에서 숨겨지고, 설정에서만 수정할 수 있습니다.

⚙ Google OAuth 설정 확인·변경
미연결 · 최초 1회 설정 후 Google 로그인을 눌러주세요.
처음 설정 방법 보기 (3단계)
  1. Google Cloud에서 프로젝트를 만들고 Google Drive API를 사용 설정합니다.
  2. Google 인증 플랫폼에서 OAuth 동의 화면을 설정합니다. 개인용 테스트 상태라면 테스트 사용자에 본인 Google 이메일을 추가합니다.
  3. 웹 애플리케이션 OAuth 클라이언트를 만들고, 승인된 JavaScript 원본에 배포 사이트 주소(예: https://아이디.github.io)를 추가합니다. 생성된 클라이언트 ID를 위 입력창에 붙여 넣으세요. PC와 모바일은 같은 웹주소·클라이언트 ID·Google 계정을 사용해야 합니다.

⚠️ file://로 연 HTML에서는 Google OAuth가 작동하지 않습니다. 무료 정적 호스팅(예: GitHub Pages)에 올려 HTTPS로 접속하세요. 이 버전의 공개 HTML에는 개인 고정비·카드·지출 내역이 들어 있지 않습니다. JSON/엑셀 백업 파일을 GitHub에 업로드하지 마세요.

가계부에서 만든 파일만 읽고 수정하도록 제한된 drive.file 권한을 사용합니다. 입력 내용은 이 브라우저에 암호화 저장되며, Google 연결 후 암호문을 Drive에 업로드합니다. 다른 기기의 변경은 화면 복귀 시 또는 약 1분마다 확인합니다. 로그인 유효기간이 끝나면 다시 로그인해야 합니다.

🔐 보안 강화: 비밀번호 원문·해시를 Google Sheets에 저장하지 않고, 입력한 암호로 JSON 전체를 암호화합니다. 기존 우리집가계부_sync.json은 이전에 평문이었다면 새 암호화 파일 생성 후 Drive에서 직접 삭제하고 휴지통도 비워주세요. 비밀번호 분실 시 복구할 수 없습니다.

⚠️ 서로 다른 두 기기에서 동시에 변경하면 충돌 경고를 표시하지만, Drive API만 사용하는 간단한 구현이라 동시에 저장되는 극히 짧은 순간의 경합까지 완전히 차단하지는 못합니다. 중요한 수정 전후로 JSON 백업을 권장합니다.

⑥ 초기화

이 브라우저에서만 가계부를 비웁니다. Google Drive의 비공개 데이터는 삭제하지 않습니다. 초기화 전에 JSON 백업을 권장합니다.
